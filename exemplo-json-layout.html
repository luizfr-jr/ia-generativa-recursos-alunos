O que o teste demonstra

O script copia coordenadas e estilos dos elementos originais. Só muda os campos content. Assim, as caixas mantêm as mesmas posições e dimensões. O texto precisa caber no espaço reservado; JSON preserva os dados geométricos, mas não impede sozinho que uma frase longa fique apertada ou cortada.

Em um caso real, um modelo de visão estimaria a estrutura a partir da imagem. Aqui, os dados estão explícitos para conseguirmos isolar e testar a etapa de edição.
